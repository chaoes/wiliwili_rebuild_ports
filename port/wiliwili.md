# Wiliwili PortMaster Port

Thanks to [xfangfang](https://github.com/xfangfang/wiliwili) for creating wiliwili, a beautiful and performant Bilibili client for handheld devices and consoles.

## Controls
| Button | Action |
|---|---|
| D-Pad / Left Stick | Navigate |
| A | Confirm / Play |
| B | Back / Cancel |
| X | Search / Secondary action |
| Y | Filter / Options |
| Start + Select | Exit |

## Requirements
- Active Wi-Fi connection
- Bilibili account login required for video playback
